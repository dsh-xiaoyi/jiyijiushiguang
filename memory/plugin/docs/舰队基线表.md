## 判据纪律（本轮新增）
```

## PS 5.1 坑清单（同名成员在两种类型上行为不同）

```

## D2 / D6 定稿（三层证明链 + 链接归一化分支）

```
D2 三层证明链
  路径层：Target 归一化后与写入目录比较
  内容层：穿越链接读哈希 == 直读哈希 == 发布值（全 64 位）
  运行层：端口属主 PID + 监听端口 + 尾巴 build + INJECT-SELFID + 实例数

D6 链接解析必须分支（相对与绝对要相反处理，Join-Path 会盲目拼接）
  if ([IO.Path]::IsPathRooted($target)) { $resolved = $target }
  else { $resolved = [IO.Path]::GetFullPath([IO.Path]::Combine($linkParent, $target)) }
  然后再归一化比较：大小写不敏感 + 去尾斜杠 + 两侧都转绝对
```
